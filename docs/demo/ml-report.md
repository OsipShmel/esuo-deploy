# Прогноз длительности обслуживания: итог в цифрах

> Синтетика мира `standard`, зерно `42`, модель `dm-report`, 304 обслуживаний отложенной выборки, собрано 2026-09-22. Пересобирается `uv run esuo-ml report`, числа воспроизводятся по зерну.

## Главное: прогноз против его отсутствия

Пенсионный день: самый нагруженный профиль, почти половина клиентов — пенсионеры с платежами.
«Без прогноза» — отделение без модели и без истории: 300 с на любое обслуживание.

| | Без прогноза | С прогнозом | Итог |
|---|---:|---:|---|
| Ошибка прогноза одного обслуживания, с | 177 | **113** | −36 % |
| Ошибка обещанного времени вызова, мин | 57,0 | **9,3** | в 6,1 раза точнее |
| Окно-часов в смене (нужно на самом деле: 37) | 23 (−38 %) | **38** (+3 %) | смена по потребности |
| Среднее ожидание клиента, мин | 94 | **4** | в 24 раза меньше |
| 90 % клиентов ждали не дольше, мин | 170 | **12** | в 15 раз меньше |
| Максимальное ожидание, мин | 191 | **22** | в 8,6 раза меньше |
| Просроченных талонов | 142 | **0** | ни одного |

Как это получается. 300 с — это примерно выдача посылки, а в пенсионный день в смеси много платежей
и пенсионеров, и настоящая средняя почти вдвое больше. Без прогноза отделение недосчитывает работу
и недобирает смену, а недобор смены прямо переходит в очередь. Прогноз не ускоряет обслуживание —
он говорит руководителю, сколько окон открыть, и клиенту — сколько честно ждать.

## По типам дней

Смена ставится по прогнозу, день проигрывается с этой сменой; окна, длительности и выбор талона
одинаковы во всех столбцах.

| День | Окно-часов: без прогноза / с прогнозом / нужно | Ожидание ср., мин: без / с прогнозом |
|---|---|---|
| Обычный день | 15 / **19** / 19 | 109 / **3** |
| Выходной | 11 / **14** / 14 | 3 / **2** |
| Пенсионные выплаты | 23 / **38** / 37 | 94 / **4** |
| Пенсионные выплаты, поток +30 % | 27 / **47** / 49 | 75 / **15** |

## Точность одного прогноза

Ошибка на обслуживаниях, которых модель не видела при обучении (MAE, секунды).

| Способ прогноза | MAE, с | Против константы 300 с |
|---|---:|---:|
| Предел точности: знает истинные параметры мира | 112,8 | −36 % |
| **Модель** | **112,6** | **−36 %** |
| Средние по истории (`handling_stats`) | 115,5 | −35 % |
| Среднее по услуге | 140,5 | −21 % |
| Константа 300 с | 176,7 | — |

Модель упёрлась в предел (112,6 против 112,8 с): точнее на этих данных не может быть никто —
остаток ошибки это случайность самого обслуживания. Средние по истории близки к модели там,
где история есть; модель выигрывает там, где её мало:

| Новый сотрудник, наблюдений | Средние по истории, с | Модель, с | Модель точнее |
|---:|---:|---:|---:|
| 5 | 278 | **236** | +15 % |
| 10 | 277 | **221** | +20 % |
| 25 | 222 | **210** | +5 % |
