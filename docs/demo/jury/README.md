# Результаты демо-сценариев для жюри

Заполняется скриптами `scripts/demo` (`./scripts/demo/run.sh …`), не тестами. См. `scripts/demo/README.md`.

- `runs.md` — таблица прогонов: время, коммит, сценарий, проверки, подпись хода событий.
- `repeatability.md` — вердикты `run.sh repeat КОД 3`: подписи трёх прогонов совпали или нет.
- `runs/*.json` — прогон целиком: факты, проверки, полный ход событий.

Результаты автотестов — отдельно, в `docs/demo/results.md`.
