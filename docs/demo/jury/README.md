# Журнал демо-прогонов

Пишется демо-сценариями (`./scripts/demo/run.sh …`) автоматически, руками не редактируется.

| Файл | Что там |
|---|---|
| [`runs.md`](runs.md) | каждый прогон строкой: время, коммит, сценарий, проверки, подпись хода событий. Журнал полный — вместе с отладочными прогонами первых дней, когда стенд собирали по частям |
| [`runs/*.json`](runs) | прогон целиком: факты (пик очереди, ожидание, решения), проверки, полный ход событий |
| [`repeatability.md`](repeatability.md) | вердикты `run.sh repeat КОД 3`: совпали ли подписи трёх прогонов подряд |
| [`ab-report.md`](ab-report.md) | отчёт последнего прогона `pension-ab`: итоги, смена по часам, ход дня |

Итоговая сводка по последним прогонам каждого сценария — [`../results.md`](../results.md), раздел 3.
